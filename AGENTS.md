# Agent Instructions

Read [CLAUDE.md](CLAUDE.md) before working here. `.claude/` is the single source of
truth for workflows, reference libraries, state ownership and the decision gates.
Use the host's equivalent tools when Claude-specific tool names are unavailable.

Two rules that override convenience: this repository holds one person's whole financial
position, so nothing that quotes an amount is ever committed; and nothing here executes a
money decision. It drafts, the user acts.
